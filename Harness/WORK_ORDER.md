# 작업 지시서

## 사용 방법

이 문서는 사용자가 AI에게 반복적으로 작업을 맡기기 위한 공용 작업 지시서다.

작업을 맡길 때 아래 템플릿의 `작업 이름`과 `상세 요구사항`에 내용을 작성한다. 사용자가 "메모 작업해"라고 말하면 AI는 이 파일을 읽고 작성된 작업을 실제로 수행한다.

## 주의사항

- 이 파일은 템플릿이므로 명시 요청 없이 구조를 지우지 않는다.
- GitHub에는 템플릿 안의 내용이 항상 주석만 있는 상태여야 한다. 실제 작업 지시 내용은 커밋하지 않는다.
- `유저 메모장`은 작업 대상으로 해석하지 않는다. 참고용 메모로만 취급한다.
- 현재 대화의 직접 지시가 이 파일보다 우선한다.
