# 화면 / UX 하네스

## 시각 방향

- 장르: 2인 플랫포머 액션 PVP
- 핵심 분위기: 짧고 빠른 템포의 레트로 대전 게임
- 색상 방향: 검정 / 회색 / 흰색 중심의 고대비 1bit 기반 제한 팔레트
- 포인트 컬러: 빨강, 파랑 계열을 소량 사용
- 폰트 방향: 픽셀아트와 어울리는 선명한 저해상도 계열
- UI 밀도: 빠른 선택과 대전 흐름을 방해하지 않는 간결한 구성

## UI 방향

- 주요 화면: 메인, 캐릭터 선택, 맵 선택, 전투, 옵션
- 입력 방식: PC 기반 2인 로컬 멀티 입력
- 플레이어 수 표시 방식: P1 / P2가 즉시 구분되어야 한다.
- 선택 화면 UX: 각 플레이어의 현재 선택, 확정 상태, 캐릭터 차이가 명확해야 한다.
- 맵 선택 UX: 노말, 얼음맵, 화염지대, 가속 발판, 점프 강화, 랜덤 맵의 특징이 구분되어야 한다.
- 옵션 / 설정 UX: 확인 필요

## 확인된 화면 / 씬 기준

- `MainScene`: 메인 진입 화면
- `OptionScene`: 옵션 화면
- `ModSelectScene`: 모드 선택 화면
- `CharacterSelectScene`: 캐릭터 선택 화면
- `Map1`: 전투 또는 맵 테스트 씬

## 캐릭터 비주얼 기준

- 전사: 검을 사용하는 기본형 근접 캐릭터로 읽혀야 한다.
- 마녀: 물약을 사용하는 원거리 캐릭터로 읽혀야 한다.
- 방망이: 강한 넉백과 차징 공격이 드러나야 한다.
- 레일건: 차징형 원거리 직선 공격이 드러나야 한다.

## 아트 검수 체크리스트

- 화면 해상도와 Canvas 스케일에서 UI가 겹치지 않는가
- 텍스트가 버튼, 패널, 화면 경계 밖으로 넘치지 않는가
- 선택 상태, hover 상태, disabled 상태가 구분되는가
- 스프라이트 해상도와 필터링이 의도와 맞는가
- 폰트, 색상, 외곽선, 배경 대비가 읽기 쉬운가
- 검정 / 회색 / 흰색 중심 팔레트와 빨강 / 파랑 포인트 컬러 범위를 지키는가
- 픽셀 경계가 흐려지지 않고 하드한 실루엣을 유지하는가
- 디더링 명암이 과하게 뭉개지지 않는가
- Unity 씬, 프리팹, 메타 파일 참조가 깨지지 않았는가
- UI 리디자인 에셋을 추가할 때 기존 `Assets/Sprite/UI` 참조와 삭제된 스프라이트 참조를 함께 점검했는가
