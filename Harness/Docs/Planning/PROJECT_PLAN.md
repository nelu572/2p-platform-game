# DUOX

## 게임 개요

- 장르 : 2인 플랫포머 액션 PVP
- 플랫폼 : PC
- 플레이 인원 : 2인 로컬 멀티
- 툴 : Unity, Aseprite

DUOX는 2명의 플레이어가 같은 공간에서 싸우는
2D 플랫포머 대전 게임이다.

플레이어는 캐릭터와 맵을 선택한 뒤 전투를 진행한다.
먼저 3번 죽는 플레이어가 패배한다.

## 핵심 컨셉

- 짧고 빠른 템포의 난전형 PVP
- 캐릭터별 다른 전투 스타일
- 낙사와 넉백 중심 전투
- 죽은 이후에도 유령으로 전투 개입 가능

## 유령 시스템

플레이어가 죽으면 유령 상태가 되어 전투에 계속 개입한다.

유령은 직접 전투보다는:
- 방해
- 위치 압박
- 이동 방해
- 낙사 유도

등에 중점을 둔다.

캐릭터마다 서로 다른 유령 행동 패턴을 가진다.

## 전투 요소

- 기본 공격
- 점프 공격
- 스킬 1개
- 낙사 시스템
- 넉백 기반 전투

## 맵 종류

- 노말
- 얼음맵
- 화염지대
- 가속 발판
- 점프 강화
- 랜덤 맵

## 아트 스타일

- 고대비 1bit 기반 제한 팔레트 픽셀아트
- 검정 / 회색 / 흰색 중심의 모노크롬 스타일
- 빨강, 파랑 계열의 소량 포인트 컬러 사용
- 선명한 픽셀 경계와 하드한 실루엣 표현
- 디더링 기반 명암 표현
- 저해상도 레트로 게임 분위기 지향

## 캐릭터

### 전사
- 검을 사용하는 기본형 근접 캐릭터
- 검격 스킬 사용

### 마녀
- 물약을 사용하는 원거리 캐릭터
- 다양한 상태이상 물약 사용

### 방망이
- 강한 넉백 중심 근접 캐릭터
- 차징 공격 사용

### 레일건
- 차징형 원거리 캐릭터
- 강한 직선 공격 사용
